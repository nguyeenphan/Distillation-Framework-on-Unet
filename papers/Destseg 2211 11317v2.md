## Abstract

Visual anomaly detection, an important problem in computer vision, is usually formulated as a one-class classification and segmentation task. The student-teacher (S-T) framework has proved to be effective in solving this challenge. However, previous works based on S-T only empirically applied constraints on normal data and fused multi-level information. In this study, we propose an improved model called DeSTSeg, which integrates a pre-trained teacher network, a denoising student encoder-decoder, and a segmentation network into one framework. First, to strengthen the constraints on anomalous data, we introduce a denoising procedure that allows the student network to learn more robust representations. From synthetically corrupted normal images, we train the student network to match the teacher network feature of the same images without corruption. Second, to fuse the multi-level S-T features adaptively, we train a segmentation network with rich supervision from synthetic anomaly masks, achieving a substantial performance improvement. Experiments on the industrial inspection benchmark dataset demonstrate that our method achieves state-of-the-art performance, 98.6% on image-level AUC, 75.8% on pixel-level average precision, and 76.4% on instance-level average precision.

## 1. Introduction

Visual anomaly detection (AD) with localization is an essential task in many computer vision applications such as industrial inspection, medical disease screening, and video surveillance. The objective is to identify both corrupted images and anomalous pixels in corrupted images. As anomalous samples occur rarely and the number of anomaly types is enormous, it is unlikely to acquire enough anomalous samples with all possible anomaly types for training. Therefore, AD tasks are usually formulated as a one-class classification and segmentation, using only normal data for model training.

The student-teacher (S-T) framework, known as knowledge distillation, has proven effective in AD. In this framework, a teacher network is pre-trained on a large-scale dataset (e.g., ImageNet), and a student network is trained to mimic the feature representations of the teacher network on an AD dataset with normal samples only. The primary hypothesis is that the student network will generate different feature representations from the teacher network on anomalous samples that have never been encountered in training.

However, there is no guarantee that the features of anomalous samples are always different between S-T networks because there is no constraint from anomalous samples during training. Even with anomalies, the student network may be over-generalized and output similar feature representations as those by the teacher network. Furthermore, aggregating discrepancies from multi-level in an empirical way (such as sum or product) could be suboptimal.

### Main Contributions

1. We propose a denoising student encoder-decoder, which is trained to explicitly generate different feature representations from the teacher with anomalous inputs.
2. We employ a segmentation network to adaptively fuse the multi-level feature similarities to replace the empirical inference approach.
3. We conduct extensive experiments on the benchmark dataset to demonstrate the effectiveness of our method for various tasks.

## 2. Related Works

**Image reconstruction.** Researchers used autoencoders, variational autoencoders, or GANs to train an image reconstruction model on normal data. The presumption is that anomalous images cannot be reconstructed effectively since they are not seen during training. However, anomaly regions still have a chance to be accurately reconstructed due to the over-generalization issue.

**Parametric density estimation.** Assumes that extracted features of normal data obey a certain distribution (e.g., multivariate Gaussian). Recent works borrow ideas from normalizing flow to approximate arbitrary distributions.

**Memory-based approaches.** Build a memory bank of normal data in training. During inference, the model selects the nearest item in the memory bank and uses similarity for anomaly scoring.

**Knowledge distillation.** Based on a pretrained teacher network and a trainable student network. Previous works improved discrimination through ensemble learning, multi-level feature alignment, and decoder architectures. These works focus on improving S-T representation similarity on normal inputs, whereas our work additionally differentiates their representations on anomalous input.

**Anomaly simulation.** Pseudo-anomalous data can be simulated for supervised training. Classical strategies (rotation, cutout) do not perform well on fine-grained patterns. CutPaste randomly copies and pastes rectangular regions. Perlin noise-based simulation produces more realistic anomalous images.

## 3. Method

DeSTSeg consists of three main components: a pre-trained teacher network, a denoising student network, and a segmentation network.

Training proceeds in two steps. In the first step, the simulated anomalous image is input to the student network, while the original clean image is input to the teacher network. The student network is trained for denoising while the teacher is fixed. In the second step, the student model is also fixed. Both networks take the synthetic anomaly image as input to optimize the segmentation network for localizing anomalous regions.

### 3.1. Synthetic Anomaly Generation

Random two-dimensional Perlin noise is generated and binarized by a preset threshold to obtain an anomaly mask M. An anomalous image Iₐ is generated by:

$$I_a = \beta (M \odot A) + (1-\beta)(M \odot I_n) + (1-M) \odot I_n$$

where ⊙ denotes element-wise multiplication, A is an arbitrary image from an external data source, Iₙ is an anomaly-free image, and β ∈ [0.15, 1] is an opacity factor. The anomaly generation is performed online during training.

Benefits: (1) Perlin noise masks are more irregular and similar to actual anomalous shapes than rectangular masks. (2) The anomaly content A can be arbitrarily chosen. (3) The opacity factor β acts as data augmentation to increase training diversity.

### 3.2. Denoising Student-Teacher Network

Unlike previous multi-level knowledge distillation approaches where the student and teacher share the same input and architecture, our denoising student network takes a paired anomalous image as input (while the teacher takes the clean image), with a distinct encoder-decoder architecture.

**Motivation for denoising.** We give the student network the task of building normal feature representations on anomalous regions, supervised by the teacher network. Since the teacher has been pre-trained on a large dataset, it generates discriminative features in both normal and anomalous regions. The denoising student network will therefore generate different feature representations from the teacher during inference on anomalous inputs.

**Motivation for encoder-decoder.** The feature reconstruction task requires global semantic information, which cannot be achieved with only a few lower CNN layers. The task resembles image denoising in feature space, making the encoder-decoder architecture a natural choice.

**Architecture details:**

- **Teacher network:** ImageNet pre-trained ResNet18 with the final block removed (conv5_x). Output feature maps from conv2_x (T¹), conv3_x (T²), and conv4_x (T³).
- **Student encoder:** Randomly initialized ResNet18 with all four blocks (S¹_E, S²_E, S³_E, S⁴_E).
- **Student decoder:** Reversed ResNet18 (downsampling replaced with bilinear upsampling) with four residual blocks (S⁴_D, S³_D, S²_D, S¹_D).

**Training loss.** We minimize the cosine distance between features from Tᵏ and Sᵏ_D, k = 1, 2, 3:

$$X_k(i,j) = \frac{F_{T_k}(i,j) \odot F_{S_k}(i,j)}{\|F_{T_k}(i,j)\|_2 \|F_{S_k}(i,j)\|_2}$$

$$D_k(i,j) = 1 - \sum_{c=1}^{C_k} X_k(i,j)_c$$

$$L_{cos} = \sum_{k=1}^{3} \left(\frac{1}{H_k W_k} \sum_{i,j=1}^{H_k, W_k} D_k(i,j)\right)$$

### 3.3. Segmentation Network

Instead of summing cosine distances from multi-level features directly, a segmentation network is appended with additional supervision signals from synthetic anomaly masks.

Both S-T networks are frozen. The synthetic anomalous image is input to both networks, and the binary anomaly mask is the ground truth. The element-wise products of normalized feature maps (X̂₁, X̂₂, X̂₃) are upsampled to the same size as X₁ (1/4 of input size), concatenated, and fed into the segmentation network.

The segmentation network contains two residual blocks and one Atrous Spatial Pyramid Pooling (ASPP) module. Output size equals 1/4 of input size.

**Loss functions:**

Focal loss:

$$L_{focal} = -\frac{1}{H_1 W_1} \sum_{i,j=1}^{H_1, W_1} (1-p_{ij})^\gamma \log(p_{ij})$$

where $p_{ij} = M_{ij}\hat{Y}_{ij} + (1-M_{ij})(1-\hat{Y}_{ij})$

L1 loss:

$$L_{l1} = \frac{1}{H_1 W_1} \sum_{i,j=1}^{H_1, W_1} |M_{ij} - \hat{Y}_{ij}|$$

Total segmentation loss:

$$L_{seg} = L_{focal} + L_{l1}$$

### 3.4. Inference

The test image is fed into both teacher and student networks. The segmentation prediction is upsampled to input size as the anomaly score map. The image-level anomaly score is computed as the average of the top T values from the anomaly score map.

## 4. Experiments

### 4.1. Dataset

**MVTec AD:** 15 categories (10 objects, 5 textures), with hundreds of normal images for training and a mixture of anomalous and normal images for evaluation. Image sizes range from 700×700 to 1024×1024 pixels. Pixel-level binary annotations provided for anomalous test images.

**Describable Textures Dataset (DTD):** Used as the anomaly source image A for synthetic anomaly generation.

### 4.2. Evaluation Metrics

**Image-level:** AUC (area under the ROC curve).

**Pixel-level:** AUC and Average Precision (AP), more appropriate for heavily imbalanced classes.

**Instance-level (IAP):** An anomaly instance is a maximally connected ground truth region. An instance is considered detected if more than 50% of region pixels are predicted as positive. IAP@k reports precision at recall = k%.

**Ground truth downsampling:** We use bilinear interpolation to downsample the binary mask to 256×256, then round with threshold 0.5 to preserve continuity without over or under-estimating.

### Failure Case Analysis

Some failures result from ambiguous ground truths (e.g., transistor cases where ground truth highlights both original and misplaced locations). Other failures come from noisy backgrounds where tiny fibers and stains are highlighted due to model susceptibility.

## 5. Conclusion

We propose DeSTSeg, a segmentation-guided denoising student-teacher framework for anomaly detection. The denoising student-teacher network enables the S-T network to generate discriminative features in anomalous regions. The segmentation network fuses the S-T network features adaptively. Experiments on the surface anomaly detection benchmark show that all proposed components considerably boost performance. Our results outperform the previous state-of-the-art by 0.1% AUC for image-level anomaly detection, 5.6% AP for pixel-level anomaly localization, and 4.9% IAP for instance-level anomaly detection.
